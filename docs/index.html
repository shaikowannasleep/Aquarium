I’m Dung, a game developer working at the intersection of playful design and technical constraints. My work centers on Unity, lightweight HTML5 games and playable ads built to load fast, run smoothly and make every tap count.

I’m drawn to emergent behavior: giving simple rules enough room to become something surprising. When I’m not making games, I’m learning more about web and backend systems.
