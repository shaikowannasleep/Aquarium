# Aquarium Asset Attribution

The fish silhouettes in this project are original vector artwork created for
the project. They are inspired by the broad anatomy of neon tetras, clownfish,
yellow tangs, butterflyfish, angelfish, and seahorses, but do not contain or
derive from Wikimedia Commons files or other third-party artwork.

No external runtime asset is loaded. This avoids hotlinking and keeps the
GitHub README SVG self-contained.
