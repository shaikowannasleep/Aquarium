Anti-Ripping & Anti-Tamper Shield

Protecting HTML5 / Luna Playable Ads from ripping & unauthorized reuse

⚠️
How HTML Ripping Happens: Attackers inspect the page network, download the single-file HTML, and re-host or extract base64 assets.

To ensure users can only play directly inside your official DinDun Playable Hub, inject this Anti-Ripping header snippet into the <head> of any exported playable build:

<script>
/**
 * DinDun Anti-Ripping & Domain Lock Shield
 * Enforces embed-only execution inside DinDun Playable Hub
 */
(function() {
    const ALLOWED = ['shaikowannasleep.github.io', 'localhost', '127.0.0.1'];
    const isFrame = (window.top !== window.self);
    let validHost = false;
    try {
        const parentHost = window.parent.location.hostname;
        validHost = ALLOWED.includes(parentHost);
    } catch(e) {
        validHost = ALLOWED.some(h => document.referrer.includes(h));
    }

    // 1. Block Standalone Execution Outside Hub
    if (!isFrame || (!validHost && location.hostname !== '')) {
        document.documentElement.innerHTML = 
            '<div style="background:#070b14;color:#00ffc2;font-family:sans-serif;height:100vh;display:flex;flex-direction:column;align-items:center;justify-content:center;text-align:center;padding:24px;">' +
            '<h1 style="color:#ff3366;font-size:24px;margin-bottom:12px;">⛔ UNAUTHORIZED PLAYABLE ACCESS</h1>' +
            '<p style="max-width:500px;color:#8da2bf;line-height:1.6;font-size:14px;">This Playable Ad is digitally protected. Direct ripping, hotlinking, or standalone execution outside DinDun Playable Hub is prohibited.</p>' +
            '<a href="https://shaikowannasleep.github.io/Aquarium/apps/playable/" style="display:inline-block;margin-top:20px;padding:12px 24px;background:#00ffc2;color:#070b14;border-radius:8px;font-weight:700;text-decoration:none;">Open in Official Playable Hub 🚀</a>' +
            '</div>';
        throw new Error("Execution blocked: Unauthorized environment.");
    }

    // 2. Disable DevTools & Right-Click
    window.addEventListener('contextmenu', e => e.preventDefault(), true);
    window.addEventListener('keydown', e => {
        if (e.key === 'F12' || (e.ctrlKey && e.shiftKey && ['I','J','C'].includes(e.key.toUpperCase())) || (e.ctrlKey && ['U','S'].includes(e.key.toUpperCase()))) {
            e.preventDefault(); e.stopPropagation(); return false;
        }
    }, true);
})();
</script>

Protection Layers Implemented:

  1. Frame Check (Anti-Busting): window.top !== window.self ensures the game never runs directly in a raw browser tab.
  2. Domain Whitelisting: Confirms the parent container belongs to shaikowannasleep.github.io or local dev environment.
  3. DevTools Interception: Blocks keyboard shortcuts (F12, View Source, Save Page) and context menus.
  4. Obfuscation Strategy: For high-tier commercial playable builds, minify and run JS through Terser/obfuscator with identifier scrambling.
