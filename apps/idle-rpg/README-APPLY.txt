COOKING GAME ASSET PACK — v1.0

Included: two 60-region atlas manifest templates, Spine 2D mukbang/ASMR skeleton scaffold and animation plan, and art direction notes.

IMPORTANT LIMITATION: this ZIP does not contain rendered atlas PNGs, finished artwork, or a compiled/validated Spine project. The JSON files are scaffolding for an artist/Spine Editor workflow, not production-ready exports. Spine does not embed ASMR audio; synchronize sound separately in the game engine.

Atlas target: 2048x2048 transparent PNG pages, 10x6 icons. Pack named regions using the manifests and update coordinates/UVs after export.
Spine: import layered artwork into Spine Editor, rig the bones/slots, key the listed animations, then export JSON + atlas + PNG using the runtime version used by your game.
